# Historical and external references

Material in this folder can help point an investigation in the right
direction, but it does not carry the same confidence as behavior verified
against the retail game.

- `ShadowFlareWeb/` is an older, incomplete SDL2/C reconstruction.
- `tables/` contains older Cheat Engine research tables.

Treat both as leads. Check addresses, data layouts, timing, and visible
behavior against the retail executable before relying on them in
OpenShadowFlare.
