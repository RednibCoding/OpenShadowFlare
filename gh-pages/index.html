Web build of OpenShadowFlare , a community effort to preserve and rebuild ShadowFlare. The game engine runs here in the browser via WebAssembly.

OpenShadowFlare uses the original ShadowFlare data files. Select your ShadowFlare install folder below to start playing. The files are read locally by the browser.

This is a live development build, not a finished release. Found a bug? Let us know on GitHub or Discord .
